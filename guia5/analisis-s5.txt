4.	Para cada uno de los tres encargos del debate, ¿usarías Bootstrap o CSS propio? Justifica con tiempo, identidad de marca,

Para la web de la segunda tienda para el lunes usaría Bootstrap, queda poco tiempo, y bootstrap soluciona el menú movil y la grilla
para usarlo inmediatamnete, la identidad de la marca se soluciona sobrescribiendo los colores del css anterior en el nuevo, el peso

la identidad de la marca sería el punto fuerte y la razón por la cual se usa el CSS, con el CSS tenemos más libertad para poner 
transiciones, animaciones, etc. que no se repitan en otra página, sobre el peso de la página sería más ligera ya que solo se 
escribiría lo necesario para funcionar y sobre el mantenimiento sería mas cómodo modificar el CSS que un bootstrap.
Para el sistema interio para los panaderos sería usar Bootstrap, permitira construir rapidamente las tablas, formularios y
todo quedaría funcional sin necesidad de hacerlo desde 0, al ser una herramienta para el personal lo estético no seria algo
importante solo importaría que sea entendible y clara, como se usará en dispositivos y una red fija el peso del bootstrap no
sería problema y sería sencillo mantenerlo porque al ser bootstrap está muy estandarizado.
